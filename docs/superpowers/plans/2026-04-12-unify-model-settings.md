# 实现计划：统一模型管理入口与流程优化

## 目标
解决设置页面中模型配置入口冗余、逻辑不一致以及嵌入模型切换缺乏安全校验的问题。

## 详细步骤

### 第一阶段：Store 层标准化
- [ ] 在 `src/stores/settings.ts` 中维护统一的模型状态。

### 第二阶段：ModelManager 增强
- [ ] 修改 `src/components/settings/ModelManager.vue`：
    - [ ] 移除内部自带的 `chatModel` 和 `embeddingModel` 自动保存逻辑。
    - [ ] 暴露 `change-embedding` 事件，允许父组件拦截并确认变更。
    - [ ] 聊天模型变更则直接通过 emit 通知或在内部处理（如果不需要安全校验）。

### 第三阶段：Settings 页面整合
- [ ] 修改 `src/views/Settings.vue`：
    - [ ] **重命名**：“Ollama 配置” -> “连接配置”。
    - [ ] **清理**：移除“连接配置”面板中的“聊天模型”和“嵌入模型” Select 组件。
    - [ ] **调整顺序**：将“模型管理”面板向上移动。
    - [ ] **逻辑对接**：将 `ModelManager` 绑定到确认对话框逻辑上。

### 第四阶段：验证
- [ ] 验证切换聊天模型能立即生效。
- [ ] 验证切换嵌入模型会弹出“重索引”警告。
