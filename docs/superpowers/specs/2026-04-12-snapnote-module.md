# 设计规格说明书：SnapNote（随记）模块

## 1. 概述
SnapNote 是 Telepathy 应用中的轻量化知识捕获模块，旨在为专业人士（律师、医生、安全专家）提供高安全性、零摩擦的碎片信息记录工具，并将其无缝转化为 AI 可感知的长期记忆。

## 2. 目标群体与核心痛点
- **目标群体**：律师、医生、工程师、科研人员。
- **核心痛点**：
    - 灵感或关键细节流失快。
    - 碎片信息无法有效地与正式文档关联。
    - 担心云端笔记泄露职业秘密（医疗隐私/案件内情）。

## 3. 功能需求（Requirement）

### 3.1 碎片记录（Permanent Catch）
- **永久存储**：默认所有记录永久保存，支持按时间轴回溯。
- **流式录入**：支持 Markdown 格式，支持图片/附件粘贴。
- **标签系统**：通过 `#` 符号快速分类，支持案件号/病历号聚合。

### 3.2 语音转文字（Voice-to-Text）
- **全本地处理**：集成 Whisper 模型（Tiny/Base版），确保语音数据不离机。
- **一键录音**：提供全局快捷键或悬浮按钮启动录音。
- **自动纠错**：利用本地 LLM 对 Whisper 转录的原始文本进行标点纠正和术语优化。

### 3.3 RAG 深度集成
- **实时向量化**：每条随记保存后 3s 内执行后台 Embedding。
- **动态上下文**：在 AI 对话中，随记的权重可以动态配置（例如：来自随记的事实优先级高于来自陈旧文档的）。
- **溯源显示**：AI 在引用随记时，需明确标注“源自随记”及“记录时间”。

## 4. 技术架构建议（Technical Spec）

### 4.1 存储层 (Storage)
- **数据库**：在现有的 SQLite 数据库中新增 `snaps` 表。
- **字段定义**：
    - `id`: UUID.
    - `content`: TEXT.
    - `tags`: JSON/TEXT.
    - `audio_path`: TEXT (可选，存放原始音频路径).
    - `created_at`: TIMESTAMP (索引).
    - `metadata`: JSON (存放坐标、关联项目 ID 等).

### 4.2 语音层 (Audio)
- **引擎**：`whisper-rs` (Whisper.cpp 的 Rust 绑定).
- **模型分发**：允许用户在设置页面独立下载 Whisper 模型（~75MB - 150MB）。

### 4.3 UI 表现层
- **位置**：侧边栏新增“随记”一级入口。
- **展示**：采用瀑布流或固定高度卡片流展示。
- **快捷键**：`Cmd/Ctrl + Shift + S` 全局唤起快速输入窗口。

## 5. 安全合规 (Security)
- **物理隔离**：随记数据库与缓存目录不参与任何形式的云同步。
- **数据导出**：支持一键导出为纯文本或加密的 JSON 文件。

## 6. 后续规划
- **自动摘要**：每周/月自动生成随记周报，协助复盘。
- **相似关联**：当用户写下一条随记时，右侧自动浮现知识库中相关的法律条文或案例。
