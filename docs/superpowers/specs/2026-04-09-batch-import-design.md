# 批量导入功能设计

## 1. 概述

为文档管理页面添加批量导入功能，支持同时导入多个文件或整个文件夹，提升用户导入文档的效率。

## 2. 用户交互

### 2.1 触发方式

- **多文件选择**：点击"导入文档"按钮，在文件选择对话框中支持 Ctrl/Cmd + 点击多选
- **文件夹导入**：新增"导入文件夹"按钮，选择文件夹后递归扫描支持的文件类型

### 2.2 支持的文件类型

- PDF (.pdf)
- Markdown (.md)
- 文本 (.txt)
- Word (.docx) - 需 sidecar 支持

### 2.3 导入弹窗

**布局：**
```
┌─────────────────────────────────────────────────┐
│ 批量导入文档                              [X]   │
├─────────────────────────────────────────────────┤
│ 文件列表：                                      │
│ ┌─────────────────────────────────────────────┐ │
│ │ 📄 document1.pdf     2.3MB    ✓ 成功        │ │
│ │ 📄 report.pdf       1.1MB    ⟳ 导入中      │ │
│ │ 📄 notes.txt        12KB     ⏳ 等待中      │ │
│ │ 📄 draft.docx       45KB     ✗ 失败 [重试]  │ │
│ └─────────────────────────────────────────────┘ │
│                                                 │
│ ████████████░░░░░░░░░░░░░░ 3/7 个文件          │
│                                                 │
│                              [取消]  [开始导入]  │
└─────────────────────────────────────────────────┘
```

**状态说明：**
| 状态 | 图标 | 说明 |
|------|------|------|
| 等待中 | ⏳ | 等待导入 |
| 导入中 | ⟳ | 正在导入（图标旋转） |
| 成功 | ✓ | 导入成功 |
| 失败 | ✗ | 导入失败，显示重试按钮 |

### 2.4 导入完成

- **全部成功**：弹窗自动关闭，Toast 提示"导入成功 X 个文档"
- **部分失败**：弹窗保持显示，用户可点击失败项重试，或手动关闭弹窗
- **完成后**：自动刷新文档列表

## 3. 前端组件

### 3.1 BatchImportDialog.vue

**Props：**
- `open: boolean` - 控制弹窗显示
- `projectId: string` - 目标项目 ID

**Events：**
- `close` - 关闭弹窗
- `complete` - 导入完成（包含成功数、失败数）

**内部状态：**
```typescript
interface ImportItem {
  id: string;
  path: string;
  name: string;
  size: number;
  status: 'pending' | 'importing' | 'success' | 'failed';
  error?: string;
}
```

### 3.2 Documents.vue 修改

- 导入按钮改为下拉菜单：包含"导入文件"和"导入文件夹"两个选项
- 点击后打开 BatchImportDialog

## 4. 后端依赖

无需修改后端 - 复用现有的 `import_document` 命令，循环调用即可。

## 5. 错误处理

- **网络错误**：标记为失败，显示错误信息
- **文件不存在**：标记为失败
- **不支持的文件类型**：跳过并记录
- **重复导入**：后端已有处理逻辑（返回现有文档或创建新的）

## 6. 限制

- 建议单次导入不超过 100 个文件，避免前端性能问题
- 大文件导入可能较慢，已在列表中显示状态
