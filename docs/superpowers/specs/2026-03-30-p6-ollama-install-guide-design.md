# P6: Ollama 安装引导 - 设计文档

## 1. 项目背景 (Project Context)

P5 已完成设置页面，支持 Ollama 地址、模型选择等配置。P6 新增 Ollama 安装引导功能，帮助用户快速安装 Ollama 并下载模型，降低使用门槛。

## 2. 核心目标 (Core Goals)

- **安装引导**: 在 Ollama 未安装/未启动时显示清晰的引导提示
- **一键安装**: 提供复制安装命令、打开下载页面
- **模型下载引导**: Ollama 已安装但无模型时，提示下载模型

## 3. 架构设计 (Architecture)

### 3.1 状态检测

复用现有 `list_ollama_models` 命令：
- 调用成功 + 有模型 → "已就绪"
- 调用成功 + 无模型 → "需下载模型"
- 调用失败 → "未安装/未启动"

### 3.2 前端状态

```typescript
interface OllamaStatus {
  installed: boolean;      // Ollama 是否可用
  hasModels: boolean;       // 是否有已安装的模型
  errorMessage?: string;    // 错误信息（用于诊断）
}
```

#### 状态 3: 已就绪（保持现有 UI）
- 显示现有的设置表单

### 3.4 交互逻辑

1. **复制安装命令**: 使用 `n-clipboard` 或 navigator.clipboard 复制命令
2. **打开下载页面**: 使用 Tauri `shell.open()` 打开 https://ollama.com
3. **检查状态**: 重新调用 `fetchModels()`，根据结果切换 UI
