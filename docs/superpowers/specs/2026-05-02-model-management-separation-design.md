# 模型管理功能独立化设计方案

## 1. 概述与背景
当前 Telepathy 的模型下载、模型市场、模型管理以及核心推理/检索参数全部嵌套在“系统设置”页面。
这导致“系统设置”页面承担了过多功能，折叠面板（Accordion）层级复杂，用户在日常管理本地模型和配置参数时交互链路冗长。

为了提升系统的可维护性和用户体验（UI/UX），本设计方案将所有模型管理、模型市场、参数配置等相关功能从“系统设置”中彻底独立出来，创建全新的顶级页面 **模型管理 (Models)**。

---

## 2. 详细设计

### 2.1 顶级页面路由与边栏导航

#### 1. 路由配置 (`src/router/index.ts`)
新增 `/models` 路径，并指向 `src/views/Models.vue` 页面。
```typescript
{ path: '/models', name: 'Models', component: () => import('@/views/Models.vue'), meta: { keepAlive: true } }
```

#### 2. 侧边栏菜单更新 (`src/components/layout/Sidebar.vue`)
在 `menuItems` 数组中，将 **模型管理** 插入到 **AI 对话** 之后。
```typescript
{ label: '模型管理', key: 'Models', icon: 'cpu' }
```
并在图标匹配部分新增 `cpu` 图标对应的 SVG 图形。

---

### 2.2 新页面：`src/views/Models.vue`

`Models.vue` 页面将整合原 `ModelManager.vue` 组件、模型选择与推理参数配置。

#### 1. 顶部标题与快速指引
- 提供清晰的标题：“模型管理”。
- 页面整体采用现代卡片流式网格（Fluid Grid）布局。

#### 2. 核心模型选择卡片 (Model Selection)
- 横向两栏并排展示：
  1. **默认对话模型 (Default Chat)**：下拉框切换默认模型。
  2. **语义检索模型 (Embedding)**：下拉框切换默认嵌入模型，并在变更时提示确认框及触发重新索引。

#### 3. 页面主体 Tab 视图
使用 `Accordion` 或原生的多 Tab 结构将页面功能分为 2 大子板块：
- **Tab 1: 模型市场与管理 (Model Hub)**
  - 继承自原 `ModelManager.vue` 的全部功能。
  - 本地已安装模型列表（横向滚动，带删除、效率标签）。
  - 为您推荐、排行榜（最受欢迎、最新发布）、全量在线搜索探索。
- **Tab 2: 高级推理配置 (Inference Settings)**
  - **检索参数**：
    - Top-K 滑块（1-20）。
    - 相似度阈值滑块（0-1，步长 0.05）。
  - **LLM 推理参数**：
    - 线程数 (num_thread)（1-12）。
    - 上下文窗口 (num_ctx)（1024-16384）。
    - 生成温度 (temperature)（0-1）。

---

### 2.3 精简 `src/views/Settings.vue`

由于所有的模型和参数都已经迁移到 `Models.vue` 页面，系统设置页将被大幅精简：

- **完全移除内容**：
  - 移除 `ModelManager` 导入及相关绑定发射逻辑。
  - 移除 Top-K, 相似度阈值, 推理参数, 以及嵌入模型重新索引的确认弹框等业务逻辑。
- **重构页面内容**：
  - **外观设置**：显示主题切换（浅色/深色/系统）、品牌主题色切换、自定义颜色。
  - **应用信息**：版本信息。
  - 由于去除了折叠选项，不再需要 AccordionRoot 组件。

---

## 3. 校验与测试标准
- **路由导航正常**：点击侧边栏的“模型管理”项可流畅跳转到 `/models` 页面，原有的设置页面能够正常通过侧边栏或标题栏跳转。
- **模型切换联动有效**：在 `Models.vue` 页切换默认对话模型和语义检索模型后，能够正常保存到 `settings` Pinia Store 并在刷新后保持持久化。
- **外观切换可用**：在精简后的 `Settings.vue` 页面修改主题色和品牌色，各页面样式能够实时生效且正确渲染。
